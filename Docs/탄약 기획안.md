# 탄약 기획안.
**목표**
보유 중인 탄약을 정의하고 총기에 연결한다. 초기 작성 당시에는 예비탄이 무한이었다. 2026-10-29 현재 유한 예비탄·재장전·드롭·상점·HUD 코드가 연결됐으며 Unity 실제 동작 확인은 사용자 검증 대기다.

## 탄약의 종류
게임에서는 4종류의 총이 존재하고, 각 계열마다 고유한 탄약을 사용한다.

1. 권총 탄약
2. 저격 탄약
3. 기관단총 탄약
4. 샷건 탄약

현재 버전에선 권총, 저격(볼트액션), 기관단총만 존재하는데, 앞으로는 샷건 또한 추가된다.
또한 같은 계열의 다른 무기들도 등장함에 따라 같은 계열 무기들을 같은 탄약을 사용하도록 한다.

## 탄약 데이터 관리
작업지침.md 의 2.데이터 에 따라 테이블화 하여 관리한다. 관리할 내용으로는 다음과 같다.
1. 각 탄약의 속성
   a. id
   b. 대표색
   c. 플레이어가 보유할 수 있는 최대 탄약
   d. name ex)권총 탄약, 샷건 탄약
2. 플레이어가 시작 시 보유하고 있는 탄약

플레이어가 보유할 수 있는 탄약은 해당 무기의 최대 장전 수(탄창 크기) * 10 으로 한다. 즉, 10탄창을 들고 있을 수 있다.(현재 장전된 탄약 제외)
ex) 권총탄: 한 탄창에 6. 최대 탄창은 60.
또한 해당 값은 추후 인게임에서 상점 등을 통해 조절될 수 있다.

플레이어는 모든 탄약을 6탄창 가진 채로 시작한다.
이는 장전된 탄약과는 별개다. 모든 무기는 최초 획득시에 탄약이 장전돼있다. 즉, 플레이어는 시작시 장전탄(한탄창) + 6탄창을 지급받은 상태로 시작한다. 모든 무기 6탄창, 권총 한 탄창(장전됨)

현재 구현된 bolt(저격총), revolver(권총), .smg(기관단총) 을 기준으로 최대 탄창을 정의한다.
현재 구현되지 않은 샷건은 한 탄창에 2발로 정의한다.

## 탄약 수급
탄약 수급처는 2종류가 있다. 1. 상점에서 구매, 2. 적의 드랍

### 상점에서 구매
상점에선 각 탄약별로 최대 수량으로 채우는 선택지가 추가된다. 각 무기별로 정해진 최대 수량만큼 보유 탄약을 회복한다.(값 올림)

가격은 모두 200원으로 한다.


### 적의 드랍
적은 본인이 사용중인 무기 종류의 탄약을 드롭한다.

드롭된 아이템을 다가가서 획득할 시, 해당 탄약의 (한 탄창 용량) / 2 만큼 해당 탄약이 회복된다.
예시) 권총탄 드롭 회득 -> 3발 회복

드롭된 아이템은 해당 라운드가 끝나면(상점 이용) 사라진다.

러셔 등의 총을 사용하지 않는 적은 총알을 드랍하지 않는다.


## 슬롯 탄약 보상과의 관계
지급 시점에 들고 있는 총의 탄창 부족분을 무료로 채운다. 예비탄과 진행 중 재장전·종료 시각은 유지한다. 보급량 2배는 구현하지 않으며 탄약 퍽의 등장 가중치 ×3만 적용한다.

## UI
게임 중에는 사용 중인 총의 장전탄과 해당 탄종의 현재 예비탄을 표시한다. 표시 방식은 좌측 하단의
"장전 탄약 / 보유 탄약" 형태로 표시한다.

재장전 표시는 탄약 수량 위에 고정된 줄을 사용한다. 월드 탄약 픽업은 색만 표시하고 이름·수량 텍스트는 표시하지 않는다. 상점 상품 설명은 'OO 탄약 보충'과 '최대량까지 보충'만 남기며 현재/최대 예비탄은 좌측 요약에 표시한다.

상점에서 모든 탄약의 수량을 표시한다.
좌측에 탄약별로 정리한다.
ex)
권총: 50
저격: 15
삿건: 10
기관단총 : 40
