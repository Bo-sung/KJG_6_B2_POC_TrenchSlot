# 상점 기획 (v1 — 2026-10-29, 기획 메모 기반 공동 작성)

> v0(5군 나열) 폐기. 메모의 4계층 구조로 재구성: **시대 / 시대무관(스탯·보급·슬롯업) / 무기(누적) / 파츠**
> 경제 기준: 시작 $50, 클리어 보너스 $100+$10×(n−1). [제안]=결정 대기
> 정정: Colt Model 1878은 리볼버가 아닌 **쌍열 산탄총**이다. 기존 리볼버 파츠 모델은 이 총과 호환되지 않으며, 산탄총 전용 파츠 외형은 새로 제작해야 한다. 기존 Colt 1878 파츠 효과는 임시로 유지한다.

## 1. 전체 구조

```
상점
├── 시대 탭? ─── 무기: 시대해금 + 누적 유지 (판매 가짓수만 증가)
│                무기 슬롯 2개 — 권총류 **아킴보 토글** (#33)
│                파츠: 무기에 종속, 무기 해금 시 함께 해금 (중복 보유 O)
└── 상설 탭 ──── 스탯 (시대 무관, 고정 진열)
                보급 (탄약)
                슬롯 업그레이드 (CloverPit/Balatro식)
```

> **경제 채널 원칙 [#34]**: 상점은 **확정 채널** — 고정 스탯·무기·**슬롯이 확률로 주는 현물(탄약·파츠)의 정가 판매**. 슬롯은 같은 현물의 확률 채널(더 싸지만 불확실). 슬롯 현물이 하나도 안 나올 때를 대비한 확정 경로가 항상 존재해야 한다. 상세: `POC-기획노트.md` §1-3

## 3. 무기 — 누적 판매제

- 시대 전환으로 **판매 목록이 증가만 함** (기존 판매분 유지) — 시대가 지나도 "구형 무기"를 사는 선택지 존속
- **누적 카운트**: 1887 3종 → WW1 +4 = 7 → WW2 +4 = 11 → 월남 +4 = 15종

### 아킴보 (쌍권총) [결정 #33]

- **권총류만 허용** — POC 대상: M1873 · 루거 P08. Colt 1878을 포함한 소총/샷건/기관총은 불가
- **장착 슬롯 2개를 전부 같은 권총 1종으로 채우는 형태**. 유저 정보의 보유 무기 영역에 **아킴보 토글 버튼** — 보유 중이면 정비시간에 무료 전환 (§10 후속 결정).
- 교환 구조:
  | 관점 | 아킴보 ON | 대가 |
  |------|-----------|------|
  | 단기 화력 | 좌우 교차 사격 = 연사 사실상 2배 | **슬롯 2개 점유 → 다른 무기 휴대 불가** (소총/샷건 카드와 자리 다툼) |
  | 지속 사격 | 탄약 소모 2배 (2정 모두 같은 탄종) | 상점 탄약가·드랍 경제 그대로 노출 |
  | 재장전 | 양손 동시, 시간 ×1.5 [제안] | 러셔 웨이브 한복판에서 재장전 = 무방비 창이 더 큼 |
- 발사 모델: 탄창 = 정(slot)별 개별 카운트(6+6), 좌우 교차 소모. 한 정 빈 채로 운용 가능 — "왼쪽 끝, 오른쪽 3발" 식의 부분 탄창 플레이 [제안]
- 피해 페널티 없음 [제안] — 이미 슬롯 2개 점유와 탄약 2배 소모로 자연 균형. 탄약 드랍(적이 쓰는 탄종)이 아킴보의 급료가 되는 구조
- 구현 의존: 무기를 드는 **슬롯 2개 모델** (현 single-weapon → dual-slot화), floating 총 모델 2개, 교차 발사 사운드. 작업 세션 지시 필요

## 4. 무기 파츠

- 무기 1개당 **3~5개**, 무기 해금 시 판매 해금
- **장착 모델 [결정 #33 개정]: 슬롯(무기 개체) 단위** — 파츠 타입(총구/총열/탄창/개머리판/조준경) = 장착 슬롯. **전부 동시 장착 가능하되 같은 타입은 1개** ("총구에 총구, 개머리판에 개머리판")
- **중복 구매·보유 허용 [결정 #33]**: 같은 파츠를 여러 개 살 수 있고, 각 **무기 개체(슬롯)에 하나씩** 장착. 아킴보(슬롯 2개 = 같은 권총) 시 **좌우 각각 파츠 세팅** — 완성 아킴보 = 파츠 비용 ×2 = 아킴보의 숨은 값 [결정 의도]
- 정리: 파츠 = (무기 종류, 슬롯 1|2, 타입) 키로 보유. **아킴보 = 같은 권총 2정(슬롯 1·2)** 이므로 파츠 효과를 양손에 다 붙이려면 중복 구매 필요 — 파츠 가격이 아킴보의 숨은 조정 밸브로 동작
- 파츠 = 무기 단위 업그레이드. 5개 다 모으면 해당 무기가 "완성형" — 무기가 자체가 아니라 **무기별 커스터마이징이 스탯 곡선의 한 축**
- 구매 = 영구(런 단위 리셋 [제안]), 장착은 즉시. 장착 기본값: 해금 시 기본 파츠 1개 장착 [제안]

## 5. 시대 무관 — 스탯 (고정 진열)

- **무한 누적 스택 [결정]**: 구매 횟수 상한 없음 (기존 "이동속도 3회"/"방어력 상한" 제한 폐기). 대신 **가격이 구매 횟수에 따라 지수 상승**
- **가격 곡선 [결정]: n회차 = 기준가 × 2.5^(n−1)** (가장 가까운 $5 단위 반올림, §10 후속 결정) — 설계 의도: **3회차가 "다음 시대가 되어야 벌 수 있는 돈" 수준**이 되도록. 그 시대 안에서는 사실상 손이 안 가고, 다음 시대 수입으로 넘어가는 순간 보이는 상품. 아래 3회차 표는 과거 $50 단위 예시다.
  - 시대별 보너스 총수입(클리어 보너스만, 처치 별도): 1887 ≈ $600 / WW1 ≈ $850 / WW2 ≈ $1,100 (5웨이브분)

| 스탯 | 효과 [제안] | 기준가 | 2회차 | 3회차 |
|------|------|:---:|:---:|:---:|
| 최대 체력 | +25 | 100 | 250 | 650 |
| 방어력 | 받는 피해 −6% | 150 | 375 | 950 |
| 이동속도 | +7% | 150 | 375 | 950 |
| 장전 속도 | −12% | 150 | 375 | 950 |
| 탄약 보유량 | 탄종 max +100 | 100 | 250 | 650 |
| 반동 제어 | −15% | 120 | — | **보류 (반동 시스템 논의 대기)** |

- 곡선 검증 (이동속도 기준): 1887 시대 수입 ~$600 → 1·2회차($150+$375)은 시대 내 구매 가능, 3회차 $950는 WW1 수입($850)+처치보상을 모아야 접근 가능 = 의도 부합
- 메모의 "기타…" 대응: 이동중 명중률? 처치 보상 +5%?(경제 스탯은 슬롯업과 영역 중복이라 신중 [제안: 넣되 "처치 보상+"는 킬 스택 토큰과 역할 분리 선언])

## 9. 상점 UI 및 무기·탄약 연동 메모 (2026-10-29)

### UI 방향 [결정]
- 기존 uGUI와 MVP 구조를 사용하고 GPM은 도입하지 않는다.
- 무기 목록과 선택 무기의 파츠, 스탯, 보급을 영역별로 표시한다. 슬롯 업그레이드는 별도 영역에 둔다.
- 유저 정보 영역은 상품 선택과 무관하게 현재 상태를 항상 표시한다. 정비 요약·소지금·구매 안내·다음 웨이브 버튼을 표시한다.

### 무기 구매·교체 [결정]
- 휴대 슬롯은 최대 2개이며 1·2번 키로 전환한다. 같은 종류의 무기를 여러 자루 보유할 수 있다.
- 시작 무기 M1873도 상점에서 다시 구매할 수 있다. 추가 구매 가격 **$60으로 구현됨**(ShopData).
- 무기 전환 시 진행 중인 재장전은 취소한다.
- 빈 슬롯이 있으면 구매한 무기를 그 슬롯에 넣고 현재 사용 무기는 유지한다. 두 슬롯이 차 있으면 교체할 슬롯을 선택하고 기존 무기는 바닥에 놓는다. 현재 사용 중인 슬롯을 교체하면 새 무기를 즉시 사용한다.
- 바닥 무기 픽업은 빈 슬롯이 있으면 그 슬롯에 넣고, 가득 찼으면 현재 사용 중인 무기와 교환한다.
- 파츠는 플레이어가 아닌 개별 무기에 종속된다. 바닥 무기는 웨이브가 지나도 남으며, 다시 주울 때 파츠와 장전 상태를 유지한다.
- 구매한 새 무기는 탄창이 가득 찬 상태로 지급하며, 해당 장전탄은 공유 예비탄에서 차감하지 않는다.

### 탄약 UI와 타 세션 연동 [주의]
- 탄종별 예비탄은 같은 탄종 무기들이 공유한다. 무기별 장전탄은 독립적이며 예비탄 수에 포함하지 않는다.
- 탄창 제한 및 탄약 관련 UI는 미리 준비하되, 실제 탄약 처리는 다른 세션에서도 작업 중이다. 현재 연결·처리는 임시 구현이 될 수 있으므로 해당 작업의 결과를 확인하고 통합 시 재검토한다. 기존 동작이나 임시 처리를 최종 규칙으로 간주하지 않는다.
- 슬롯 탄약 심볼 [결정]: 공유 예비탄을 차감하지 않고 현재 무기의 탄창을 즉시 채운다. 실제 탄약 처리 연동은 타 세션 작업과 통합 시 재검토한다.

### 슬롯 업그레이드 [결정 및 미결]
- 최초 진열 시 2종을 추첨한다. 구매 후 빈 칸을 즉시 채우지 않으며, 전부 구매한 뒤 다음 웨이브 종료 시 갱신한다 (§10 결정).

## 10. 총기·상점 추가 결정 (2026-10-30)
- 무기 유효 거리는 발사체가 비행할 수 있는 최대 거리이며, 해당 거리에 도달하면 발사체가 사라진다. 거리별 피해 감소는 결정 대기.
- 헤드샷 기본 피해 배율은 1.5. 헬멧 착용 시 피해를 줄이며, 첫 버전 헬멧은 파괴되지 않는다. 머리·헬멧 명중 피드백을 구분하고, 산탄은 머리에 맞은 산탄에만 헤드샷 배율을 적용한다. 헬멧 감소율의 구체 수치는 미결이며 머리 피해가 몸통보다 낮아지지 않도록 제한하는 방향.
- 파츠 [개정]: 같은 파츠의 중복 구매·보유를 허용하며, 각 파츠 개체는 한 번에 한 무기에만 장착한다. 같은 종류의 무기 두 자루에도 각각 파츠를 장착할 수 있다. 분리한 파츠는 보관했다가 무료로 재장착할 수 있으며, 바닥 무기에 장착된 파츠는 무기를 주워야 분리할 수 있다.
- 슬롯 업그레이드는 2개 상품 중 일부만 구매하면 남은 상품과 빈 칸을 유지한다. 전부 구매한 뒤 다음 웨이브 종료 시 새 2개를 진열하고, 구매 제한에 도달한 업그레이드는 추첨에서 제외한다. 후보가 부족한 칸은 품절 처리한다.
- 탄약 팩 125발, 파츠 가격 소속 무기 가격의 35%는 임시 기준이며 탄약 작업 및 시작 무기 가격 확정 후 재검토한다. 스탯 가격은 기준가 × 2.5^(구매 횟수)를 가장 가까운 $5 단위로 반올림한다.
- 무기 상세 스탯은 무기 판매 영역에 표시하고 유저 정보 영역은 현재 상태를 항상 표시한다.
- 리볼버·레버액션·볼트액션은 기본 이동속도 유지, 무거운 총기는 감속한다. 세부 배율은 미결.
- 저지력 [결정]: 피해와 별도로 적에게 저지력을 누적한다. 적별 저항 기준에 도달하면 짧은 경직과 공격 중단이 발생하고, 발동 후 잠시 면역을 두어 연속 경직을 방지한다. 저지력은 적중이 없으면 서서히 감소한다. 일반 적은 저항이 낮고 중장 적은 저항이 높으며 넉백도 약하다.
- 자동 무기는 발당 저지력이 낮고 리볼버·소총은 높게 설정하는 방향. 넉백은 산탄총 등 지정 무기에 주로 적용한다. 산탄은 한 발의 저지력을 합산하되 상한을 두고 넉백은 발사당 한 번 적용하며 적중 산탄 수와 거리의 영향을 받는다. 헤드샷은 피해에만 배율을 적용하고 저지력 보너스는 주지 않는다. 세부 수치는 플레이테스트 후 결정한다.

### 구현 준비 추가 결정
- 총기별 수치는 실총 제원과 게임 사례 조사(`reports/총기 제원과 게임 사례.md`)를 바탕으로 작성한다. 게임용 수치는 조사 사실과 구분하고 플레이테스트로 조정한다.
- 현재 4개 계열 탄약은 기획의 세부 탄종으로 확장한다. 예비탄·장전탄 처리 시 최신 탄약 시스템과 통합한다.
- 상점 UI·데이터, 무기 슬롯·총기, 파츠, 헤드샷·저지력 및 탄약 연동을 한 번에 구현하는 범위로 진행한다. 이후 사용자 지시로 구현에 착수했다.

### 2026-10-30 상점 UI·아킴보 후속 결정
- 상점은 무기·파츠와 상시 판매 스탯을 왼쪽에, 유저 정보·보급·슬롯 업그레이드를 오른쪽에 배치한다. 아킴보 전환은 무기 판매 영역이 아니라 유저 정보의 보유 무기 슬롯에서 처리한다.
- 같은 권총 두 자루를 휴대하면 정비 시간에 아킴보를 무료로 전환한다. 각 무기의 탄창과 파츠는 별도다. 아킴보 중 1·2번 입력은 이미 두 무기를 들고 있으므로 무시하며 무기 교체 시 아킴보를 해제한다.
- 양손 동시 장전 시간 1.5배, 예비탄 부족 시 장전 우선순위, 아킴보 상태의 슬롯 탄약 보상은 임시 처리로 플레이테스트 및 탄약 세션 통합 시 재검토한다.
